# Fabric Data Ingestion & Streaming Pipeline

## Overview

This is a hands-on Microsoft Fabric data engineering project.

The project demonstrates batch data ingestion, data transformation,
pipeline orchestration, Lakehouse processing, and real-time streaming.

## Technologies

- Microsoft Fabric
- Dataflow Gen2
- Fabric Pipelines
- Lakehouse
- PySpark
- Delta Lake
- Eventstream
- Eventhouse
- KQL

## Project Modules

### Module 1 — Dataflow Gen2
Visual ETL using Dataflow Gen2, transformations, and Lakehouse output.

### Module 2 — Pipelines
Copy pipelines, parameters, dynamic content, scheduling,
incremental loading, and troubleshooting.

### Module 3 — Lakehouse & Notebooks
PySpark, DataFrames, Parquet, Delta tables, SQL queries,
and notebook chaining.

### Module 4 — Eventstream & Eventhouse
Real-time streaming using Eventstream and Eventhouse,
transformations, and multiple destinations.

## Architecture

The project contains both batch and real-time data processing paths.

More details will be added as each module is completed.
